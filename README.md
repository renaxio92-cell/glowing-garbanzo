# glowing-garbanzo

A minimal Next.js 16 foundation prepared for the personal video streaming website described in the project Master Prompt.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Zod
- Lucide React

## Scripts

```bash
npm install
npm run dev
```

## Repository and branch

This project is being developed on the GitHub repository:

https://github.com/renaxio92-cell/glowing-garbanzo

The current working branch is:

setup/nextjs-foundation

## Notes

- This is the initial foundation stage only.
- Additional providers, metadata configuration, UI implementation, and deployment validation will be added in later stages.
- Keep environment secrets out of the repository and manage them in Vercel or local environment files only.
